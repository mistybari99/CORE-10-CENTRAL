## Order and concurrency
Start DR01 and DR08 (independent upstream bug discovery) in separate research sessions if quota allows; DR01 is required for definitive no-loss claims, not for read-only discovery. DR02–07/09 can gather source evidence independently once scope is pinned, then reconcile against DR01. DR10 waits for DR01–09 evidence or explicitly marks missing parts; no fake completeness. Run two sessions at a time as practical default; don't consume quota repeating broad prompts. If allowance limited, DR01 first, then DR02, DR04, DR05, DR03, DR06, DR08, DR07, DR09, DR10. Recheck current UI quota; don't assume entitlement.
