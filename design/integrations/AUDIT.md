# Integration Ports — Audit (read-only)

Date: 2026-11-10. Branch `design/integration-ports` from origin/main.
Method: grep of repo root JS (minified bundles, so evidence is by RPC/table names), SQL in `internal/`, and SELECT-only catalog/count queries on the live project (table/function names, row counts, and the non-secret registry flags only; no personal data, no secret values read).
Status words follow the repo protocol: only BUILT / TESTED IN ISOLATION are claimed anywhere here; nothing is STAGING VERIFIED.

## 1. Headline

The database side of the ports mostly EXISTS already and is OFF: `integration_registry` has 13 rows, all `enabled=false, status=not_connected, read_only=true, dry_run=true`. What is missing is the SERVER side: there is no repo-tracked Edge Function or worker that sends a message, receives a webhook, or calls a provider (the only `functions/v1` reference in the repo is `scan-extract`, in `scan.js`, and its source is not in git). Today "WhatsApp/SMS" in the UI means opening `wa.me` / `sms:` links on the phone, not an API send.
