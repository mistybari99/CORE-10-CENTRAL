## One deviation from the Final Decisions file

access tables are referenced by every module, 35 loaders and 7 browser clients, so the whole line
was renamed at once. There is now one schema; fixtures are rows loaded by tests. Side Draft PRs
written against `c10_demo` need the same rename when reconciled.
